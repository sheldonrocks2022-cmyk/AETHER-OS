# AETHER OS

Native Kotlin Android home launcher prototype.

## APK build

Go to Actions → Build Android APK → select a successful run → Artifacts → AETHER-OS-debug-APK.

## Features in v0.1.0

- Registers as Android Home launcher
- Dark gradient home screen
- Installed-app list, icons, app launch, and search

This is an early prototype. Theme customization, a dock, widgets, and gestures are planned, not implemented. Builds use JDK 17, Gradle 8.9 and Android SDK 35.
